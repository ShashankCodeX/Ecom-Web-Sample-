# NOIR VEIL — Luxury Fashion Storefront

A single-page storefront demo built with HTML, CSS, and JavaScript. It includes a product collection, product-order modal, and WhatsApp order links. It has no payment or inventory backend.

## Preview locally

Open `index.html` in a browser, or serve this folder locally:

```sh
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## Customize

- Replace the sample product photos and update the product names and prices in `index.html`.
- Replace the placeholder WhatsApp number in the page before using the order links for a real business.
- Google Fonts are loaded from the web, so the page needs an internet connection for those fonts.
